
# Assignment 7: Continuous Integration Using Jenkins and GitHub

## Aim
To integrate Jenkins with GitHub and create a Continuous Integration (CI) pipeline that checks out source code, builds the application, and runs automated tests.

## Objectives
- Understand the fundamentals of Continuous Integration.
- Store project files in a GitHub repository.
- Configure Jenkins to retrieve code from GitHub.
- Automate build and test stages using a Jenkinsfile.
- Verify successful builds and investigate failures.

## Tools Required
- Git
- GitHub
- Jenkins
- Java Development Kit (JDK)
- Visual Studio Code

## Pipeline Stages
1. Checkout source code from GitHub.
2. Build and validate the sample application.
3. Run automated tests.
4. Display the final build status.

## Practical Work
The pipeline will be executed, the source code will be modified and pushed to GitHub, and a deliberate test failure will be introduced and investigated.
